# Humanity.sh — نسخهٔ دسکتاپ

**هر نقطه، یک زندگی.**

از نسخهٔ ۰٫۲، موتور اصلی برنامه با پایتون نوشته شده است. پنجره با PySide6 ساخته می‌شود و ظاهر HTML/CSS/JavaScript در همان پنجره نمایش داده می‌شود. تصمیم‌گیری، حافظه، شخصیت، احساسات و ساعت جهان در پایتون اجرا می‌شوند.

## اجرای برنامه

پایتون ۳٫۱۱ یا جدیدتر لازم است:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[desktop]"
python -m humanity.desktop
```

در ویندوز، دستور فعال‌سازی محیط `.venv\Scripts\activate` است. در مک، پس از نصب وابستگی‌ها می‌توانی روی `Humanity.command` دوبار کلیک کنی. نیازی به نصب Node.js یا اجرای سرور جداگانه برای نسخهٔ دسکتاپ نیست. پس از نصب، برنامه بدون اینترنت و ورود به ChatGPT کار می‌کند.

## از کجا کد را بخوانم؟

۱. `humanity/engine/models.py`: تعریف فرد، شخصیت، احساسات، نیازها، باورها، خاطره و جهان، با dataclassهای پایتون.

۲. `humanity/engine/decision.py`: گزینه‌های رفتاری و عامل‌های مؤثر بر انتخاب آن‌ها.

۳. `humanity/engine/perception.py`: تبدیل اتفاق بیرونی به برداشت شخصی، احساس درونی و واکنش ظاهری.

۴. `humanity/engine/actions.py`: پیامد کارهایی مانند کمک، گفت‌وگو، استراحت و تلاش.

۵. `humanity/engine/simulation.py`: زمان، ترتیب اجرای ماژول‌ها، دخالت در شرایط و ذخیره‌ها.

۶. `humanity/desktop/`: پنجره، پل ارتباطی و رشتهٔ کاری پایتون. منطق جامعه به این پوشه وابسته نیست.

برای اضافه کردن قابلیت جدید، [معماری](architecture.md) و [فرض‌های مدل](model.md) را ببین.

## آزمایش بدون پنجره

```sh
python -m humanity.cli --population 48 --seed hello-friend --steps 240 --save world.json
python -m humanity.cli --load world.json --steps 24
```

یا مستقیماً از پایتون استفاده کن:

```python
from humanity import Simulation

world = Simulation(seed="hello-friend", population=48)
world.step(24)
world.set_condition("pressure", 0.7)
print(world.world.agents[0].identity.name)
```

## ذخیره‌ها و ادامهٔ زندگی

دکمهٔ ذخیره، یک نقطهٔ بازگشت دستی روی دستگاه می‌سازد. بستن برنامه، نشست فعلی را در فایل جداگانه ذخیره می‌کند. پس از باز شدن دوباره، جهان از همان نشست و در حالت متوقف ادامه می‌یابد. پنهان شدن پنجره، زندگی جهان را متوقف نمی‌کند؛ بستن کامل برنامه آن را متوقف می‌کند.

ذخیره‌ها در پوشهٔ دادهٔ برنامه در سیستم‌عامل قرار می‌گیرند. برای انتخاب مسیر مشخص:

```sh
python -m humanity.desktop --data-dir ./my-worlds
```

فایل `world.json` ذخیرهٔ دستی و `session.json` آخرین نشست است. برای شروع تازه از `--fresh` استفاده کن. در صورت خراب بودن ذخیرهٔ نشست، فایل قبلی به‌عنوان پشتیبان نگه داشته می‌شود.

ذخیره‌های JSON نسخهٔ وب قابل بازکردن هستند. از مرورگر «دریافت فایل» را بزن و در دسکتاپ «بازکردن فایل» را انتخاب کن. ذخیرهٔ داخل localStorage مرورگر خودکار به برنامه منتقل نمی‌شود.

## آزمون‌ها

```sh
python -m unittest discover -s tests_python -v
```

برای آزمون تطابق با موتور قبلی، Node.js نسخهٔ ۲۲ یا جدیدتر لازم است؛ برای خود برنامه لازم نیست.

نسخهٔ وب قبلی برای سازگاری و مقایسه باقی مانده و موتور JavaScript مستقل خود را دارد. برنامهٔ دسکتاپ از آن موتور استفاده نمی‌کند.

این نسخه یک مدل اکتشافی است. عددهای شخصیت و قواعد رفتاری فرض‌های طراحی‌اند و نتایج به‌تنهایی ادعایی دربارهٔ جامعهٔ واقعی ثابت نمی‌کنند. کد پروژه با MIT منتشر شده است؛ فونت و وابستگی‌ها لایسنس مستقل خود را دارند.
