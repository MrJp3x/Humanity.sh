# Humanity.sh

**هر نقطه، یک زندگی.**

این پروژه یک آزمایشگاه اجتماعی قابل بازی است. هر فرد هویت، شخصیت، ارزش‌ها، باورها، نیازها، احساسات و خاطره‌های خودش را دارد. جامعه از انتخاب‌ها و تجربه‌های این افراد شکل می‌گیرد.

## اجرای پروژه

Node.js نسخهٔ ۲۲ یا جدیدتر لازم است. نیازی به نصب پکیج، کلید API یا سرویس هوش مصنوعی نیست.

```sh
git clone git@github.com:MrJp3x/Humanity.sh.git
cd Humanity.sh
npm run dev
```

سپس نشانی `http://127.0.0.1:4173` را باز کنید.

## استفاده از رصدخانه

۱. «ادامهٔ زندگی» را بزنید؛ هر گام برابر یک ساعت است. برای بررسی دقیق‌تر، زمان را متوقف کنید و گام‌به‌گام جلو بروید.

۲. روی یک نقطه در نقشه کلیک کنید یا از بخش «ساکنان» فردی را انتخاب کنید. چهار زبانهٔ پرونده، ذهن و رفتار، هویت، خاطره‌ها و رابطه‌های او را نشان می‌دهند.

۳. در بخش «آزمایش‌ها»، خبر پیشرفت یک فرد را منتشر کنید. یک واقعیت مشترک می‌تواند در شاهدان، شادی، حسادت یا تردیدهای متفاوتی ایجاد کند. برداشت درونی و رفتار آشکار جدا نمایش داده می‌شوند.

۴. شرایط جهان را تغییر دهید و زندگی را ادامه دهید. فراوانی امکانات، امنیت اجتماعی و فشار محیط بر وضعیت و تصمیم‌ها اثر می‌گذارند.

۵. برای امتحان دو آینده از یک نقطه، جهان را ذخیره کنید، یک مسیر را ببینید، به ذخیره برگردید و شرایط دیگری را امتحان کنید. ذخیره در مرورگر دستی است. فایل JSON نیز قابل دریافت و بازکردن است.

جهان تازه با ۶ ساعت زندگی شبیه‌سازی‌شده شروع می‌شود تا از همان ابتدا تجربه‌ای برای مشاهده وجود داشته باشد. هنگام پنهان شدن صفحه، زمان متوقف می‌شود. بدون ذخیره، بازخوانی صفحه جهان فعلی را از دست می‌دهد.

## توسعه

هستهٔ شبیه‌سازی از رابط کاربری جداست. ماژول‌ها در چهار مرحلهٔ مشخص اجرا می‌شوند و وضعیت ویژهٔ خودشان را در فضای افزونه‌ها نگه می‌دارند. برای افزودن قابلیت جدید، [معماری](architecture.md) و [فرض‌های مدل](model.md) را بخوانید.

این نسخه شبیه‌سازی کاملی از انسان واقعی نیست. وزن‌های تصمیم‌گیری فرض‌های طراحی هستند و نتایج به‌تنهایی ادعایی دربارهٔ جامعهٔ واقعی ثابت نمی‌کنند. کشور، اقتصاد مالی و سیاست هنوز پیاده‌سازی نشده‌اند.

کد با لایسنس MIT منتشر شده است. فونت فارسی لایسنس مستقل OFL دارد.
